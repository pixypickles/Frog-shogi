カエルしょうぎ v0.8.1

練習モード
- 水中戦の左上に「練習に戻る」ボタンを常時表示
- 戦闘終了後のボタンも「練習に戻る」
- 練習結果は将棋盤へ送らず、training.htmlへ戻る
- 蓮の葉練習も戦闘後は練習画面へ戻る

縦型水中・ラファエル再修正
- 前＋パンチ：水圧カッター（相手方向へ発射）
- 上＋パンチ：エア（水圧）ブレード（大型・相手方向）
- 下＋パンチ：エアギロチン（上から垂直落下）
- 上＋キック：高速バブル上昇
- 下＋キック：高速バブル下降
- 高速バブル移動は既存の泡エフェクトを使用し、約0.34秒で大きく上下移動
- 縦型では旧横型ラファエル技の入力を無効化
