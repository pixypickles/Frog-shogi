カエルしょうぎ v0.8.2

修正
- 水中練習中の「練習に戻る」が旧水中タイトルへ戻る問題を修正
- 練習中は左上の戻るボタンから必ず training.html の水中練習へ戻る
- 戦闘終了後の「練習に戻る」も同じ戻り先

縦型水中・ラファエル
- 重複していた旧ラファエル技判定を整理
- 前＋パンチ：水圧カッター（相手方向）
- 上＋パンチ：エア（水圧）ブレード
- 下＋パンチ：エアギロチン
- 上＋キック：高速バブル上昇
- 下＋キック：高速バブル下降
- 縦型では旧「上＋ガード高速バブル移動」を無効化
- 高速バブル移動は specialType=raphaelBubbleMove を使用するため、全身泡エフェクトが表示
- 約0.30秒で画面高の最大40%を上下移動するよう高速化
