カエルしょうぎ v0.9.7

ガブリエル大幅変更

- ガード連打（3回）：
  ミストクラウド
  体の周りに濃い霧・雲を発生させ、本体を見えにくくする

- 上＋ガード：
  ウォータージェット上昇
  両足から水ジェットを出して急上昇

- ジェット上昇中＋パンチ：
  ジェットアッパー
  水ジェットの勢いを乗せた上昇パンチ

- 上＋パンチ：
  スカイウォーターフォール
  敵の上空から滝のように大量の水を落とす

- 後ろ＋キック：
  クラウドレインショット
  画面左右の流れる雲側から極小ダメージの小型水弾を大量発射

- 下＋キック：
  ファイブウォーターバースト
  極小ダメージの小型水弾を5方向へ放出
  発射後は雲上戦の共通誘導で敵へ収束

- 後ろ＋パンチ長押し：
  ウォーターマス
  上空に水の塊を作り、長押し中に巨大化
  離すと敵の上空から落下
  長く溜めるほど大きく高威力

演出
- ミストクラウドの白い霧
- 両足から伸びる水ジェット
- 長押し中の巨大化する水塊
