ジィハルさん調整

ボルトショット
- 発射時に相手の現在位置へ直接照準
- 上下差も含めて発射方向を補正
- 見た目の雷も進行方向へ回転

ライトニングダッシュ
- 発動時の敵位置から進行方向を自動選択
- 真横 / 斜め上45度 / 斜め下45度 の3択
- 真上・真下には飛ばない
- 高さ差が小さい場合は真横

サンダーチャージ
- 溜め解除時の敵位置へ直接照準
- 上下差も含めた2D方向へ突進
- ヒット後もその方向へ通り抜ける

隠し技：サンダーピラー
- 下方向からスティックを一回転＋パンチ
- 敵のいるX位置の上空に黒い雲が出現
- 約0.34秒後、雲から画面下まで一筋の雷
- 高威力
