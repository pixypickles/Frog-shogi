池将棋MIX 試作 v0.1
====================

目的
----
FROG FIGHTER 2 の蓮の葉ジャンプ版 / 水中版を将来接続するための、
「将棋盤部分だけ」の最初の試作です。

今回入っているもの
------------------
- 縦持ちスマホ向け 9×9 池将棋盤
- 蓮の葉マス / 水中マスの地形表示
- 天使軍 / 悪魔軍の仮配役
- 王・飛・角・金・銀・桂・香・歩の基本的な移動
- 駒取り時の戦闘判定
- 戦闘は未接続なので「攻撃側勝利」「防御側が耐える」を手動選択
- 防御側HP 33% は表示だけ（実戦闘接続時に適用予定）
- リセット

まだ入れていないもの
--------------------
- jump v2.49 / water v2.0.18 本体との接続
- 成り
- 歩→カワズさん
- 持ち駒・駒打ち
- 王手 / 詰み判定
- CPU
- キャラ画像
- キャラ固有の役割補正

注意
----
これは通常将棋ではなく、各駒種を1ネームドずつにしたカスタム編成です。
通常将棋の金・銀・桂・香は各2枚ですが、この試作では1枚ずつです。
