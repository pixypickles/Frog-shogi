カエルしょうぎ v0.10.0

ガブリエル再設計

廃止
- ミストクラウドを完全削除

上＋パンチ：スカイウォーターフォール
- 小さい水弾の雨を廃止
- 敵位置に一本の長い滝を生成
- 画面上端から敵の下までつながる縦長の水流
- 滝に触れている間、細かく連続ダメージ

後ろ＋キック：クラウドレインショット
- 背景を流れる雲側から小型水弾を大量発射
- 極小ダメージ

下＋キック：スカイレインバースト
- 旧ファイブウォーターバーストを廃止
- クラウドレインショットと同じサイズ・同じ極小ダメージの弾を
  敵上空から大量に降らせる

後ろ＋パンチ長押し：ウォーターマス
- ガブリエル本人の頭上に表示する方式を廃止
- 画面上空、敵位置の上に水塊を生成
- 長押し中にその場で巨大化
- 最大チャージ時は旧版より大幅に巨大
- 離すと巨大なまま落下
- チャージ量に応じてサイズ・威力・落下速度が変化
