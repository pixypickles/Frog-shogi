カエルしょうぎ v0.9.9

ガブリエル安定化・演出修正

ミストクラウド
- 固定雲オブジェクト方式を廃止
- ガブリエルの位置から7つの軽量な雲を発生
- 発生後はガブリエルに追従せず、そのまま横方向へ流れて消える
- フリーズ原因になりやすい独立雲管理を使わない

クラウドレインショット
- ミストクラウドとの連動を廃止
- 最初から背景を流れている雲を発射元とする演出へ戻した
- 画面上部〜中段の流れる雲側から極小ダメージ水弾を大量発射

ウォータージェット
- 足から下方向への噴射は維持
- 上昇時間と噴射表示時間を同期
- 上昇終了時に即座に消える
- ジェットアッパーへ移行した場合も通常ジェット表示は即消える
