カエルしょうぎ v0.11.1

グランドトルネード修正方針を変更。

重要：
0.10.3では「グランドトルネード！」の表示までは簡単に出ていたため、
入力判定を新しく作り直すのをやめ、0.10.3の判定コードへそのまま戻した。

復元した発動判定
- input.commandHistory を使用
- 8方向の回転履歴から時計回り/反時計回りを判定
- 1.25秒以内
- 6方向以上の連続回転で成立
- trySpecial の先頭で通常の方向＋パンチより先に判定

一方、フリーズ原因だった竜巻本体は旧実装へ戻していない。
- 専用 raphaelTornadoes 配列は使用しない
- 通常の water2Shots へ巨大な竜巻1個だけ生成
- 発動判定と「グランドトルネード！」表示は0.10.3相当
- 竜巻本体だけ軽量版

つまり今回は「出ていた頃の入力判定」と「フリーズしにくい新しい竜巻本体」を組み合わせた。
